# MIR evidence agent / وكيل LXR

الهدف: منصة مستقلة من WADJ Studio تستخدم سرعة جمع ومعالجة البيانات لبحث فرص صغيرة أو كبيرة ذات جدوى صافية بعد التكاليف. الربحية المستمرة هدف بحث وقياس، وليست وعدًا. MIR — Orbital Intelligence هو المنتج، وLXR — Liquidity X-Ray محركه الداخلي. `mir.wadj.online` نطاق مبدئي ولم يُنشر.

## ما يعمل الآن

`packages/agent/index.mjs` مخطط قائم على قواعد قابلة للمراجعة، وليس نموذج لغة أو نظام تعلم آلي. يجمع مشاهدات الاكتشاف الموجودة حسب هوية التوكنات، ويرتب مهام استكمال الأدلة. فرق السعر بين سوقين يرفع أولوية البحث، ثم تُطلب أدلة سلوك التوكن وتقييم الغاز وإعادة التسعير بأحجام محددة. البول الفارغ ينتظر السيولة، والمصدر الوحيد يحتاج سوقًا ثانيًا.

درجة الأولوية 0–3 ليست احتمال ربح أو درجة أمان. كل قرار يسجل أسبابه وبصمة البلوك. الصافي مجهول، ولا ينتج هذا المخطط عمليات تنفيذ أو paper fills. معادلات LXR الحالية تشمل رسوم البول وأثر الحجم؛ الغاز وفحص التوكنات في البيانات الحية لم يكتملَا.

ذاكرة دائمة تمنع إعادة نفس القرار؛ حد الدورة 20 قرارًا، مع آخر 2048 بصمة وآخر 256 قرارًا. العمل المؤجل لا يُسجل كمنجز. الذاكرة والتقرير والتاريخ تُحفظ في ملف واحد باستبدال ذري، وقفل يمنع تداخل عمليتين. بعد انهيار غير نظيف افحص العملية قبل إزالة قفل قديم يدويًا. السجل التالف يوقف التشغيل ولا يُصفّر بصمت.

يرفض بيانات العينات، والالتقاط الأقدم من 30 دقيقة أو المؤرخ مستقبلًا، وتراجع رقم البلوك أو اختلاف بصمته عند نفس الارتفاع. هذه فحوص اتساق محلية؛ فحص السلسلة canonical يقع في مجمّع الاكتشاف. وقت الالتقاط ليس إثباتًا لحداثة السوق. لا يوجد اعتماد لربحية أو سلامة من فرق سعر وحده.

## التشغيل

```sh
npm run discover
npm run agent
npm run agent -- --watch
```

للتجميع المتكرر شغّل `npm run discover -- --watch` منفصلًا. الوكيل يقرأ التقارير المخزنة ولا يطلق RPC. فترة إعادة القراءة 15 ثانية لإشارة فرق تحتاج أدلة، و60 ثانية للمشاهدات الأخرى، و120 ثانية عند غياب البيانات. هذا لا يجعل بلوك finalized آنيًا ولا يضمن السبق على المنافسين.

الملف `data/agent/journal.json` مستبعد من Git. `processingMs` قياس قراءة الملفات والتخطيط قبل كتابة السجل؛ لا يشمل جمع الشبكة أو التعدين. البيانات المفقودة لا تُستبدل بأمثلة. الواجهة تعرض اكتشاف LXR وبحث الأحجام المحفوظ عبر `/api/research`. مراجعة الوكيل في الصفحة معاينة فقط لا تكتب قرارات. أمر CLI يحفظ ذاكرة وتاريخ البحث بصورة مستقلة عن ذاكرة الاكتشاف، حتى لا يختلط ارتفاع بلوك كل مصدر.

## الطريق إلى وكيل أوسع

تقدم حالي: [بحث الأحجام والتكاليف](SIZING.md) يقارن أحجامًا متعددة، يحتفظ بـbase fee من نفس البلوك، ويحسب سيناريو غاز ومخصص عدم يقين بأرقام صحيحة. يظل الصافي الحقيقي مجهولًا؛ وحدات الغاز وpriority fee افتراضات صريحة، وربط النتائج بالوكيل والواجهة يعمل الآن؛ متابعة النتائج الورقية لم تكتمل بعد. [سياسة إعادة استخدام المشاريع](OPEN-SOURCE-REUSE.md) تميز التكامل الفعلي عن مجرد الترشيح.

1. قياس p50/p95 لزمن الحدث ← الالتقاط ← التقييم، والفشل والتكرار واستهلاك RPC، مع فهرسة أحداث قابلة للاستئناف.
2. موصلات قراءة بمهلات وحدود تزامن ومعدل، وcache حسب chain/blockHash/address، ومقارنة بصمات المصادر. لكل مورد سجل قدرات ورخص وتكلفة؛ لا وصول غير محدود.
3. أحجام متعددة ضمن حدود السيولة، وتقييم الغاز بوحدة quote عند نفس اللقطة، ومخصص عدم اليقين. لا تُجمع قيم WETH وUSDC كربح واحد دون تحويل موثق.
4. سجل ورقي دائم يربط الفرضيات بالملاحظات اللاحقة، واختبارات خارج العينة للانزلاق والضرائب وMEV وتأخير البيانات. القياس: الصافي الافتراضي بعد التكلفة، drawdown، الإشارات الكاذبة والتغطية.
5. مساعد استدلال اختياري يشرح الأدلة ويقترح مهام ضمن أدوات قراءة وميزانية محددة. لا يتجاوز بوابات المخاطر، ولا يحوّل محتوى خارجيًا إلى إذن مالي. هذا التكامل غير موجود بعد ولا يحتاج مفاتيح في هذه المرحلة.

لا توجد محفظة أو مفاتيح خاصة أو موافقات توكن أو إرسال معاملات. التنفيذ المالي الحقيقي خارج هذا الإصدار. مرجع SDK تحت `tools/rea` يختبر التسعير فقط.

تقدم القياس: [بحث البوولز المكتشفة](discovery-search.md) يسجل زمن الجمع والتحليل بصورة منفصلة، وp50/p95 للطلبات المنطقية المكتملة بما فيها الطلبات الفاشلة وإعادة المحاولة الداخلية. هذه عينة دورة واحدة؛ زمن الحدث إلى التقييم وعدد محاولات الشبكة الفعلية ما زالا مجهولين. لا تُستخدم هذه الأرقام كإثبات لميزة تنفيذية أو ربح.

## متابعة أمامية للفرضيات

أمر `npm run paper:forward` يثبت فرضية من آخر بحث محفوظ، ثم يقارن نفس الحجم والمسار والسياسة بلقطة لاحقة بعد وقت التسجيل. يحتفظ بسجل ذري محدود دون تغيير رصيد أو إنشاء fills. هذه متابعة لتسعير احتياطي تحت افتراضات، وليست اختبار تنفيذ أو إثبات ربح. السجل مستقل عن دورة الوكيل؛ لا يشغّل جمعًا أو مراقبة تلقائيًا. راجع [السياسة والتشغيل والحدود](FORWARD-EXPERIMENTS.md).
